# Pokémon Egg Clicker

Static web game deployed to the existing Vercel project `pokemon-egg-clicker`.

Production URL: https://pokemon-egg-clicker.vercel.app

Deployment files: `index.html`, `world_hd_1.webp` through `world_hd_8.webp`, and `world_pika_sheet.png`.

Preserve the browser localStorage key `pokeEggV2` across releases.
